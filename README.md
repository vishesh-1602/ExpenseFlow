# 💸 ExpenseFlow — Personal Expense Tracker

ExpenseFlow is a personal expense tracking web application built with HTML, CSS, JavaScript, Python Flask, and SQLite. It aims to help users manage their daily spending, track expenses, and understand their spending habits through a simple, user-friendly dashboard.

## ✨ Features

- ➕ **Add Expenses:** Record an expense with its amount, category, and description.
- 📋 **View Transactions:** Retrieve and display recorded expenses.
- 🗑️ **Delete Expenses:** Remove an expense when needed.
- 💰 **Expense Summary:** View total spending and the number of transactions.
- 💾 **Database Storage:** Store expenses in an SQLite database.
- 🎨 **Modern Dashboard:** A clean, dark-themed interface.
- 🔌 **REST API:** Flask endpoints connect the frontend to the backend.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Webpage structure |
| CSS3 | Styling and responsive layout |
| JavaScript | Frontend interactions and API requests |
| Python | Application logic |
| Flask | Backend framework and API |
| SQLite | Expense data storage |
